# myoperator-design

Designs screens that match production myOperator UI exactly — all 45 core myoperator-ui components as verified markup with verbatim Tailwind classes.

**The canonical home of this skill is [Ankish8/myoperator-design-skill](https://github.com/Ankish8/myoperator-design-skill).** This plugin carries the same v2.1.0 skill so that anyone who installed it from this marketplace gets the current version on update:

```
/plugin update myoperator-design@myoperator-plugins
```

On the Claude Team plan the organization-provisioned skill already covers everyone; if you have both, uninstall this plugin to avoid two skills with the same name.
